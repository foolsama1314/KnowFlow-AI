## 1. 软件使用说明书

### 1.1 界面结构

左侧导航固定为：工作台、资料管理、语义检索、智能问答、多文档分析、研究报告、系统设置、任务中心。

### 1.2 导入资料

1. 进入「资料管理」，点击右上角「导入资料」。
2. 支持 PDF、Word（docx）、TXT、Markdown。可一次选择多个文件。
3. 上传后系统自动解析、分块、调用真实 Embedding 建立向量索引。
4. 列表展示文件名、类型、导入时间、解析状态、索引状态、页数与文本块数量。
5. 重复文件会按内容哈希拦截；空文件、损坏文件会给出明确失败原因。

### 1.3 语义检索

1. 进入「语义检索」，输入自然语言问题。
2. 结果按相似度排序，展示来源文件、页码与原文片段。
3. 点击结果可跳到文档详情并定位页码。
4. 检索依赖 Embedding 配置；未配置时会提示去「系统设置」填写。

### 1.4 智能问答（RAG）

1. 进入「智能问答」，新建或选择会话。
2. 输入问题后以 SSE 流式显示回答。
3. 回答正文使用 `[1]`、`[2]` 编号；服务端会校验编号对应的文档、页码和原文。
4. 下方区分「AI 实际引用」与「仅检索到的相关资料」，未引用资料不会冒充引用。
5. 点击引用可跳转到原文页码；会话与消息自动保存，重启后仍在。

### 1.5 多文档分析 / 智能总结

1. 进入「多文档分析」，左侧选择 1–8 份已完成资料。
2. 输入主题，选择「联合分析」或「智能总结」。
3. 联合分析输出共同观点、差异分析、关键知识点；
   智能总结输出核心观点、关键概念、重要结论、待研究问题。
4. 每个结论带 `[编号]` 来源，引用列表可点击定位原文档页码。
5. 资料不足或相关度低于阈值时明确拒答，不调用模型编造。
6. 资料较多时自动控制上下文长度，并提示“部分资料被截取”。

### 1.6 研究报告

1. 进入「研究报告」，输入研究主题，选择参与资料。
2. 系统逐篇检索、调用真实 LLM 生成结构化报告：标题、研究背景、核心内容、关键发现、综合分析、结论、参考资料。
3. 报告在软件内预览，可导出 Markdown 或 DOCX。
4. 历史报告保存在 `data/exports/reports/`，可再次打开预览与下载。
5. 未配置 LLM、资料不足、上下文截断均有明确提示。

### 1.7 系统设置

- **大模型（LLM）**：接口地址、模型名称、API Key，可测试连接。
- **Embedding**：接口地址、模型名称、API Key、向量维度，可测试连接。
- **处理参数**：分块大小、重叠长度、默认检索条数、上传大小上限。
- **RAG 参数**：检索条数、拒答阈值、上下文长度。
- **数据备份与恢复**：见 1.8。
- 页面顶部会根据配置情况提示哪些 AI 功能不可用。
- API Key 仅保存在本机 `data/settings.json`，接口不回传明文，也不会写入日志。

### 1.8 数据备份与恢复

1. 设置页「数据备份与恢复」可一键备份。
2. 备份包含：SQLite 数据库、上传原文件、Qdrant 向量数据、非敏感配置。
3. 默认**不包含 API Key**；勾选“包含 API Key”会在确认后写入，仅限本机保存。
4. 备份文件为 ZIP，内含 `manifest.json` 与 SHA256 校验。
5. 恢复前系统会自动生成 `pre-restore-*.zip`；校验失败或恢复失败会自动回滚当前数据。
6. 恢复期间请勿进行文档处理或索引重建。

### 1.9 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示未配置 Embedding | 到设置页填写 Embedding 地址、模型、Key、维度并测试连接 |
| 提示未配置 LLM | 到设置页填写大模型地址、模型、Key 并测试连接 |
| 问答拒绝回答 | 资料不足或相似度低于阈值；可更换问法、补充资料，或在设置中调整阈值 |
| 重建索引失败 | 检查 Embedding Key、网络与额度；失败时旧索引不会被替换 |
| 备份失败 | 等待文档任务结束；确认程序目录可写 |
| 恢复失败 | 按提示使用 `pre-restore-*.zip` 恢复，当前数据已自动回滚 |

## 3. 技术架构说明

```text
Windows 桌面层：pywebview + WebView2
        │ 随机端口 + /api/v1/system/health 健康检查
        ▼
后端：Python 3 + FastAPI + Uvicorn
  ├─ API 层：system / settings / documents / tasks / search / chat / analysis / reports / backup
  ├─ 服务层：document / pipeline / index / search / rag / chat / analysis / report / backup
  ├─ 数据层：SQLAlchemy + SQLite（文档、页面、文本块、任务、会话、消息、索引状态）
  ├─ 向量层：Qdrant（本地文件模式或服务模式）
  └─ AI 适配：OpenAI 兼容协议（Embedding / LLM，可在设置中更换）
        ▲
        │ 静态资源打包
前端：Vue 3 + TypeScript + Vite + Element Plus
```

- 打包：PyInstaller（`desktop.spec`），单文件 EXE，前端静态资源内置。
- 数据目录：EXE 同级 `data/`，包含 `database/`、`uploads/`、`qdrant/`、`exports/`、`backups/`、`logs/`、`settings.json`。
- 索引进度、索引状态、文档状态均由后端真实维护，不使用前端假数据。

## 4. 核心技术与创新点

1. **全链路可追溯 RAG**：检索命中 → 上下文构建 → 模型回答 → 编号校验 → 引用对象返回，每一步都在服务端校验真实文档与页码。
2. **引用与检索分离**：回答实际引用的资料标记 `cited=true`，仅检索到的资料单独展示，避免“检索到即引用”的假象。
3. **逐文档检索的多文档分析**：按文档限定检索并做字符预算，不把多篇文档全文拼接；资料超长时明确提示截断。
4. **安全备份恢复**：SQLite 一致性快照、Qdrant 本地复制/服务模式点导出、manifest + SHA256 校验、自动预备份与失败回滚、默认脱敏。
5. **真实索引原子重建**：临时集合完整构建并校验数量后再原子切换，失败不影响旧索引。
6. **数据驱动的拒答阈值**：使用真实知识库问题记录分数（0.71 / 0.55 / 0.50），据此将默认阈值调整为 0.50，并保留可调。
7. **桌面级异常收敛**：模型未配置、Key 无效、额度不足、网络中断、超时、SSE 中断、解析/索引失败均转为中文提示，不暴露 Python 堆栈。

## 5. 安装及启动步骤

### 5.1 运行环境

- Windows 10/11 64 位。
- Microsoft Edge WebView2 Runtime（Win10/11 通常已内置；缺失时安装微软官方运行库）。
- 无需安装 Python、Node.js 或数据库。
- 程序目录需具备写入权限（不要放在 `C:\Program Files` 等受保护目录）。

### 5.2 启动

1. 将整个 `release` 目录复制到本机可写位置，例如 `D:\知枢AI\`。
2. 双击 `知枢AI.exe`。
3. 程序会自动选择随机端口、启动本地服务并打开桌面窗口。
4. 首次启动会在同级生成 `data/` 目录。

### 5.3 首次配置

1. 打开「系统设置」。
2. 配置 Embedding（地址、模型、Key、维度），点击「测试连接」。
3. 配置 LLM（地址、模型、Key），点击「测试连接」。
4. 回到「资料管理」，点击「重建向量索引」，等待完成。
5. 之后即可使用检索、问答、分析、总结与报告。

> 交付的 EXE 与演示数据**不包含任何 API Key**。请使用自己的模型服务配置。

## 6. 评委体验流程（约 8–10 分钟）

1. **启动**：双击 `release\知枢AI.exe`，展示桌面窗口与工作台统计。
2. **资料管理**：查看演示资料的文件名、页数、解析状态、索引状态与索引概览。
3. **导入**：导入 `samples/企业知识管理实践指南.docx`，观察解析与索引完成。
4. **语义检索**：提问“RAG 的核心流程是什么”，展示真实相似度与来源页码，点击定位原文。
5. **智能问答**：提问并展示 SSE 流式回答、`[1]` 引用、“已引用/仅检索到”区分、点击跳页。
6. **多文档分析**：选择 3 份资料，输入“这些资料对知识管理落地有哪些共同建议和差异？”，展示共同观点、差异、关键知识点与引用。
7. **智能总结**：选择单篇资料，展示核心观点、关键概念、重要结论、待研究问题。
8. **研究报告**：输入“企业知识管理与 RAG 技术落地”，选择资料生成报告，预览并导出 Markdown / DOCX。
9. **备份**：在设置页点击「立即备份」，展示备份列表；说明恢复会自动预备份并可回滚。
10. **异常提示**：临时清空 LLM Key，展示问答/分析/报告的明确不可用提示（可选）。
